## Đối chiếu SQL và truy vấn

SQL tham chiếu dùng `JdbcTemplate`, không gọi repository tổng hợp của ứng dụng:

```sql
SELECT transaction_date, type, SUM(amount) AS total_amount
FROM transactions
WHERE user_id=? AND transaction_date>=? AND transaction_date<?
GROUP BY transaction_date, type;
-- Tổng tháng so riêng bằng COALESCE(SUM(amount),0) theo owner/type/cùng khoảng ngày.
```

Hồi quy query hiện có: 90.000 transaction, 3 user ×3 tháng; kỳ được chọn 10.000 dòng, 62 nhóm, 2 warmup/5 mẫu. MySQL 8.0.46 chọn `idx_transactions_user_date(user_id,transaction_date)`, access `range`, estimated rows 21.374; `Using index condition; Using temporary; Using filesort`. Query min/median/max **10.440/11.037/12.508 ms**. Đây là đo local với điều kiện test, không là SLA/VPS benchmark; không thêm index hoặc sửa schema. Metadata isolation mặc định của DB test: `REPEATABLE-READ`; ca isolation đặt rõ RR, không áp kết luận cho các request phân trang chạy trong transaction riêng khi dữ liệu đang thay đổi.
